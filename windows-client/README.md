# 亚马逊跨境电商专属本地网络极速优化大师 (Windows 客户端)

> 本文件夹为专供本地电脑使用的 Windows 客户端工具，与 Linux VPS 端脚本完全独立分离。

---

### 📂 文件说明

* **`AmazonSpeedOptimizer.exe`**：
  * **Windows 桌面端主程序（已编译好的独立绿色版）**；
  * 双击即可直接运行，无需安装任何环境；
  * 拥有专属圆角火箭图标，支持暗黑/明亮双主题、关闭最小化到系统右下角托盘、开机自启；
  * 一键锁定最优东京 CloudFront 节点（双路热备），100% 兼容翻墙软件规则分流（不影响 Facebook/Google 等）。
* **`app.ico`**：
  * 专属高清圆角火箭应用图标（支持 256/128/64/48/32/16 多分辨率）。
* **`AmazonSpeedRocket.user.js`**：
  * 配套的【图片秒开 + 贴边置顶火箭】油猴/篡改猴脚本。
* **`AmazonSpeedOptimizer.cs`**：
  * Windows 客户端完整开源 C# 源码。

---

### 🚀 使用方法

1. 直接双击运行 **`AmazonSpeedOptimizer.exe`**；
2. 点击界面上的 **【⚡ 一键开启亚马逊极速直通】** 按钮；
3. 打开指纹浏览器（HubStudio / AdsPower 等）刷新亚马逊卖家后台，即可享受毫秒级秒开体验！
